# Configure Dual Boot with Limine on Omarchy

This guide explains how to add Windows or other Linux installations to the boot menu on **Omarchy 4.5 or later**,
display the menu for six seconds, and optionally organize its entries into groups.

**Before you begin:** Omarchy must already boot normally through Limine, and the other operating systems must already be
installed. This guide does not cover installing operating systems or partitioning disks. Have recovery media or an
alternative firmware boot option available.

> **Important:** This guide uses Omarchy's standard configuration file, `/boot/limine.conf`. If the file does not exist,
> your system uses a different configuration, or boot protections prevent you from editing it, stop and consult the
> relevant documentation; do not guess another path.

## 1. Create a backup

Check that the file exists and save a copy before running the scanner, as the scanner may modify it:

```bash
sudo test -f /boot/limine.conf && echo 'Configuration found'
sudo cp -a /boot/limine.conf /boot/limine.conf.backup
```

Continue only if `Configuration found` appeared and the copy completed without errors. Keep this backup while testing
the configuration.

## 2. Add Windows or other Linux systems

Run the tool recommended in the Omarchy manual:

```bash
sudo limine-scan
```

Follow the on-screen prompts and select **only boot entries you recognize** (for example, Windows Boot Manager). If you
want to add multiple targets, repeat the command as needed.

The scanner adds registered EFI entries; it does not guarantee detection of every installed operating system. If the
expected target does not appear, do not invent paths or blindly add entries by hand.

## 3. Configure menu visibility

Open the configuration file:

```bash
sudoedit /boot/limine.conf
```

Find these global options and adjust their values. If an option is missing, add it alongside the other global options,
before the menu entries:

```text
timeout: 6
quiet: no
remember_last_entry: yes
```

| Option                     | Effect                                             |
| -------------------------- | -------------------------------------------------- |
| `timeout: 6`               | Waits six seconds before booting automatically.    |
| `quiet: no`                | Displays the menu during the countdown.            |
| `remember_last_entry: yes` | Remembers the last entry whose boot was attempted. |

Do not duplicate these options or modify `default_entry`, kernel parameters, EFI paths, colors, or theme images. When a
remembered selection exists, it takes precedence over the default entry.

## 4. Organize entries (optional)

You can leave the menu exactly as generated by `limine-scan`. If you prefer to group Windows and other distributions,
edit `/boot/limine.conf` again and change **only the headings** of external entries.

For example, an existing Windows entry:

```text
/Windows Boot Manager
    protocol: efi
    path: <existing path>
```

Can be placed under a `/Windows` group:

```text
/Windows
    //Windows Boot Manager
        protocol: efi
        path: <same existing path>
```

These snippets are illustrative: **do not copy** the `<...>` placeholders or replace the actual `path` value. In Limine,
`/` identifies a top-level entry and `//` identifies a nested entry. A `+` in a heading controls whether a group starts
expanded; preserve Omarchy's existing markers.

A conceptual menu layout might look like this:

```text
/Omarchy
    //Original entries and snapshots
/Windows
    //Windows Boot Manager
/Linux
    //Another distribution
```

Create only the groups you need. **Do not change or regroup Omarchy's original entries and snapshots.** If
`default_entry` is present, grouping or reordering entries may change which target it selects. In that case, skip
grouping unless you can verify that the same operating system will still boot by default.

## 5. Check and reboot

Review the changes against the backup:

```bash
sudo diff -u /boot/limine.conf.backup /boot/limine.conf
```

It is normal for `diff` to show differences: they should consist only of the added entries, the three menu options, and
any headings you changed. **Do not proceed if you see unexpected changes** to paths, parameters, snapshots, or Omarchy
settings.

Reboot normally and verify that:

1. The Limine menu appears for approximately six seconds with its usual appearance.
2. Omarchy boots successfully and retains its entries and snapshots.
3. Windows or the other selected systems boot successfully.
4. On returning to the menu, Limine remembers the last attempted entry (not necessarily a completed boot).

## Recovery and maintenance

If the menu stops working, use the alternative boot option or recovery media you prepared. If you can still boot Omarchy
and **no kernel or snapshot updates have occurred since the backup**, you can restore the original file:

```bash
sudo cp -a /boot/limine.conf.backup /boot/limine.conf
```

If updates have occurred, **do not restore the entire file**: you could lose newly generated entries. Compare the
versions and undo only the changes made by this guide.

Omarchy 4.5 states that updates preserve a customized `timeout`, but this **does not guarantee** that groups and all
manual settings will survive configuration regeneration. If the menu changes after an update, inspect the current file
before reapplying options or headings.

**Cases outside this procedure:** booting directly without showing Limine, targets not offered by `limine-scan`,
nonstandard EFI configurations, or Secure Boot protections. Consult the Omarchy documentation and do not force changes
in those cases.
